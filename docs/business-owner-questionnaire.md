# Recommended defaults (used for anything left blank)

If you don't specify otherwise, the project will proceed on these assumptions.
You can change any of them later, but changing some after building is more work.

| Topic | Default we will use |
|---|---|
| Business type | Both **renting and selling**. |
| Property types | Apartments, houses, townhouses/maisonettes, studios/bedsitters, plus commercial (offices, shops). Land only if you list it. |
| Short-stay lets | **Not** included. |
| Areas served | **You must provide this** — there is no safe default. The area search cannot be finished without it. |
| Services shown | Selling/marketing, letting support, property search on behalf of clients, landlord representation. Wording kept general until you supply it. |
| Property management / valuation / relocation | **Not** advertised unless you confirm K Pearl offers them. |
| Contact details | Shown as placeholders until you provide the real phone, WhatsApp, email, and address. **The site cannot go live with placeholders.** |
| Off-market properties | **Hidden** from the website until available again. |
| "Price on request" | **Allowed**. |
| Location detail shown | **Neighbourhood/area only**; exact address kept private to staff. |
| Owner contact details on listings | **Recorded privately** for staff. |
| Enquiry stages | New → Contacted → In progress → Closed. |
| Team access levels | **Administrator** and **Agent** (two levels). Agents can edit any property. No two-step login for now. |
| "List your property" | Included as a simple form; your team follows up and creates the listing. |
| Viewing requests | Simple request form; your team arranges the appointment manually. **No automatic calendar.** |
| Customer accounts | **None.** Visitors browse and contact you without signing up. |
| Legal pages | **You must provide** reviewed Privacy Policy and Terms, and get advice on the Data Protection Act. Required before launch. |
| Logo & photos | **You must provide** the additional logo files and property photography. Required before launch. |
| Website copy | We draft it, **you approve it**. No invented facts. |
| Testimonials | **Not** shown until you supply real, approved ones. |
| Analytics | A **privacy-friendly** visitor counter (no cookie pop-up). |
| Email alerts on new enquiries | **On.** |
| Homepage | Shows both hand-picked "Featured" properties and the newest listings. |
| Hosting & domain | Standard modern hosting; **you provide the domain name**. |
