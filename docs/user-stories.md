# K Pearl Agency — User Stories

## Visitor

### US-001 Discover K Pearl
As a visitor, I want to understand K Pearl Agency and its services so that I know whether to trust and contact the agency.

### US-002 Browse properties
As a property seeker, I want to browse available properties so that I can find suitable options.

### US-003 Search properties
As a property seeker, I want to search by location or keyword so that I can narrow the catalogue.

### US-004 Filter properties
As a property seeker, I want to filter by price, type, bedrooms and other supported attributes so that I can find relevant properties faster.

### US-005 View property
As a property seeker, I want a detailed property page so that I can evaluate a property before contacting K Pearl.

### US-006 Enquire
As a property seeker, I want to enquire about a property so that K Pearl can respond to me.

### US-007 Request viewing
As a property seeker, I want to request a viewing so that I can see the property.

### US-008 Contact agency
As a visitor, I want to contact K Pearl for general assistance.

## Staff

### US-009 Staff login
As a staff member, I want secure access to the admin area.

### US-010 Manage properties
As authorized staff, I want to create, edit and archive property listings.

### US-011 Manage media
As authorized staff, I want to upload and reorder property images.

### US-012 Publish controls
As authorized staff, I want to publish/unpublish listings and mark featured/verified status.

### US-013 Manage enquiries
As staff, I want to see and update incoming enquiries so that none are lost.

## Acceptance rule

Every story must have explicit acceptance criteria before implementation begins.
