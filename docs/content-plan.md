## Property content

Every listing should have:
- Accurate title.
- Accurate location.
- Transparent price.
- Property facts.
- High-quality images.
- Clear availability.
- Reference code.
- Contact CTA.

Never invent property facts.

## SEO content

Each property needs:
- unique title
- meta description
- clean slug
- useful descriptive copy
- appropriate structured data where practical
