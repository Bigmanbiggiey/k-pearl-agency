# K Pearl Agency — Content Plan

## Homepage

Hero:
- Clear agency value proposition.
- Property search CTA.
- Strong property/brand imagery.

Featured properties:
- 4–8 carefully selected listings.

Agency value:
- Why clients should trust K Pearl.

Services:
- Final services confirmed with business owner.

Areas:
- Final service areas confirmed with business owner.

CTA:
- Enquire / Call / WhatsApp / Request viewing.

## Property content

Every listing should have:
- Accurate title.
- Accurate location.
- Transparent price.
- Property facts.
- High-quality images.
- Clear availability.
- Reference code.
- Contact CTA.

Never invent property facts.

## SEO content

Each property needs:
- unique title
- meta description
- clean slug
- useful descriptive copy
- appropriate structured data where practical
